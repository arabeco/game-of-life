# GAME OF LIFE - SYSTEM MANIFESTO

## 1. UI/UX PRINCIPLES
- **Estética:** Dark Mode absoluto (#000000). Use apenas cores Neon para feedback.
- **Identidade:** O design deve ser High-Tech/Cyberpunk, não amigável ou corporativo.
- **Proibição de Componentes Padrão:** Nunca use calendários estilo Google ou listas de tarefas comuns. O Planner deve ser uma linha do tempo vertical (06h-22h).
- **Física de Interação:** O único gesto de conclusão permitido é o Long-Press de 3000ms. Cliques simples não concluem tarefas.

## 2. LOGIC & DATA RULES
- **Zero Gamification:** Proibido o uso de "XP", "Energia", "Pontos" ou scores de RPG. O sistema lida com Fatos (Níveis de 0 a 10) e Execução (%).
- **Hierarquia de Dados:** Um Ativo é a raiz. Arenas são metas vinculadas a um Ativo. Pílulas são unidades de tempo vinculadas a uma Arena.
- **Sincronização Reativa:** Se uma pílula é concluída no Planner, a porcentagem da Arena correspondente deve atualizar imediatamente no estado global.
- **Protocolo de Hiato:** Sempre verificar a data do último login. Se > 3 dias, disparar a limpeza de pílulas pendentes e desativar o brilho das esferas.

## 3. PROHIBITIONS (NUNCA FAÇA)
- **Não implemente chats ou IAs:** O sistema funciona apenas com tutoriais de texto estático e comandos diretos.
- **Não use notificações invasivas:** O usuário é soberano. Alertas apenas para Rituais ou quebra de Contratos Hardcore.
- **Não permita edição de Níveis fora da Aba Maestria:** Os níveis dos Ativos na Aba 1 são apenas leitura. A alteração só ocorre via Oráculo ou Modo Soberano na Aba 4.
- **Não acumule passado:** Pílulas de dias anteriores que não foram concluídas devem ser deletadas. O sistema foca no "Agora".

## 4. DESIGN TOKENS
- **Neon Ativo 10 (Físico):** #FF0000 (Vermelho Intenso)
- **Neon Ativo 8 (Trabalho):** #00FF00 (Verde Matrix)
- **Neon Ativo 7 (Finanças):** #FFFF00 (Amarelo Ouro)
- **Neon Ativo 3 (Mente):** Dinâmico (conforme Spectrum)
- **Geral:** Transparência Glassmorphism (0.05) e Blur (10px).
