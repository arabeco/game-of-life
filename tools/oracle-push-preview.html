O que a imagem acrescenta?

O ícone do app já identifica quem falou. Compare uma notificação só com texto, uma atmosfera sem logo e uma assinatura pequena. O mesmo conteúdo aparece nas três.

Como ler esta comparação

São simulações de layout, não capturas de notificações Android. O quadrado testa um recorte central possível. O sistema controla ícone, cores, texto, expansão e miniatura; aparelhos podem exibir de outra forma. Os botões desenhados são ilustrativos.

As cores ajustadas ainda são candidatas: dourado #947322, azul #2475AC e verde #24844F. Uma única cor é usada nos dois temas para não simular uma adaptação que o servidor não controla. A opção original permite comparar. A cor aplicada pelo sistema pode ser diferente.

Sem envio de push, sem dados de conta e sem mudanças no app ou servidor. A leitura do ciclo/rodada usa o motor V2. Início, conquista e Sabedoria são exemplos editoriais para estudar o visual. Nenhuma cor representa atraso ou cobrança. A imagem é opcional; a opção A também é uma entrega válida.
